  1. Entrá a console.firebase.google.com con tu cuenta y creá un proyecto.
  2. Compilación → Firestore Database → Crear base de datos → modo producción, región southamerica-east1.
  3. Compilación → Authentication → Comenzar → habilitá Google.
  4. En Authentication → Settings → Authorized domains, agregá el dominio donde abrís la app.
  5. Configuración del proyecto → Tus apps → Web → registrá la app y copiá el bloque firebaseConfig.
  6. Pegalo acá arriba y tocá Conectar proyecto.

Esos datos no son secretos: viajan en cualquier app web. Lo que protege tus datos son las reglas de firestore.rules, que atan cada documento a tu usuario.
